# TF16 CIM Releases logo

The logo is the UCA TF16 logo next to "CIM Releases" and the CIM Model Management logo, following the CIM Model Management brand kit (the same branding as the CIM Model Managers Report).

| File | Use |
|---|---|
| `tf16-reports-logo.svg`, `tf16-reports-logo-1200.png` | Combined logo for light backgrounds (the README in GitHub's light mode) |
| `tf16-reports-logo-dark.svg`, `tf16-reports-logo-dark-1200.png` | Combined logo for dark backgrounds (the README in GitHub's dark mode) |
| `tf16-reports-mark.svg`, `tf16-reports-mark-<size>.png` | The UCA TF shield and lightning bolt alone (the same mark on every TF site), for icons (16 to 512 px) |
| `favicon.ico` | Browser icon (16, 32 and 48 px); the same file is at `docs/favicon.ico` |
| `tf16-reports-social-1280x640.png` | GitHub social preview (upload under Settings › Social preview) |

"CIM Releases" is set in Arial Bold (rendered with the metric-identical Liberation Sans Bold) and converted to outlines, so the SVGs need no fonts. The website's navy header is built in HTML and CSS from the logos in `../brand/`; see `docs/index.md` and `docs/assets/css/style.scss`.
