This site publishes UCA TF16's releases of the CIM Market package (formerly IEC62325). It includes the release that corresponds to the current International Standard as well as the interim releases of work in progress toward the next edition of IEC 62325-301.

For the current International Standard, the site provides the UML model of IEC 62325-301 Ed 2.0 (CIM03v17b) and comparison reports between published editions. Each interim release is listed with its release notes and a [cim-compare](https://cim-compare.ucaiug.io/) report of what changed in the UML. The interim models themselves (Sparx EA project files) are available only to TF16 participants, through the UCA TF16 site, until the final stable release is made public, so active participation is encouraged.

Comparison reports were generated with cim-compare [x.y.z].
